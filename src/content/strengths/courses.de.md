Wissen weitergeben zu können ist für uns eine Herzensangelegenheit. Wir engagieren uns seit vielen Jahren in der Berufsbildung, speziell bei den Informatikberufen sowie im neuen EDB-Beruf.

Gerne bereiten wir einen massgeschneiderten Kurs für die Bedürfnisse Ihrer Lernenden vor. Bereits erfolgreich durchgeführt haben Kurse mit folgenden Inhalten:

- HTML, CSS und JavaScript Grund- und Aufbaukurse
- React und Typescript Grundkurse
- Datenbankkurse, z.B. mit MariaDB oder MongoDB
- Java ORM Kurse, JPA
- Linux Grundlagenkurs
